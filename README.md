# Hi, I'm André Moreira 👋

Researcher and systems analyst at **PUC-Rio** in Rio de Janeiro, Brazil.
I work where **computer graphics**, **computer vision** and **AI** meet, with a focus on real-time 3D rendering and large-scale 3D data on the web.

## 🔭 What I'm working on

- **3D Tiles and web streaming**: loading and rendering massive 3D datasets in the browser
- **GPU rendering performance**: batching, instancing and multi-draw techniques
- **3D data and AI**: applying machine learning to point clouds and 3D scenes
